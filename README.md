# 🐍 ShadowFox Python Development Internship

A collection of Python programming tasks and projects completed as part of the **ShadowFox Python Development Internship**.

This repository demonstrates practical implementation of Python fundamentals, problem-solving, Object-Oriented Programming, web scraping, game development, and an advanced Python-based project.

## 🎯 About the Project

The purpose of this repository is to document and showcase the practical work completed during the ShadowFox Python Development Internship.

The internship tasks are organized into three levels:

- 🟢 **Beginner Level** – Python fundamentals and programming logic
- 🟡 **Intermediate Level** – Practical Python projects
- 🔴 **Advanced Level** – One advanced project based on the available internship options

The repository is structured so that each task can be independently explored and understood.

# 📚 Tasks Covered

## 🟢 Beginner Level

The Beginner level focuses on the core concepts of Python programming.

The following five sections are covered:

### 1. Variables

Concepts include:

- Variables
- Data types
- Floating-point values
- Python keywords
- Arithmetic operations
- Simple Interest calculation

### 2. Numbers

Concepts include:

- Number representation
- `format()` function
- Octal representation
- Mathematical calculations
- Area calculation
- Speed calculation
- Type conversion

### 3. Lists

Concepts include:

- Creating lists
- Accessing list elements
- `len()`
- `append()`
- `remove()`
- `insert()`
- `index()`
- Replacing list elements
- Sorting lists

### 4. If Conditions

Concepts include:

- `if`
- `elif`
- `else`
- Comparison operators
- Logical operators
- `in` operator
- User input
- Conditional decision-making

Examples include:

- BMI calculation and classification
- Identifying the country of a city
- Checking whether two cities belong to the same country

### 5. For Loops

Concepts include:

- `for` loops
- `range()`
- Counters
- Conditional statements inside loops
- Repeated operations
- User input

Examples include:

- Dice rolling simulation
- Counting specific dice results
- Detecting consecutive results
- Repetition-based exercises

# ▶️ How to Run

